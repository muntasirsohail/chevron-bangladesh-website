# Chevron Bangladesh Website

A modern, responsive website for Chevron Bangladesh showcasing operations, departments, careers, and sustainability initiatives.

## Features

✨ **Modern Design**
- Clean, professional layout matching Chevron's brand guidelines
- Smooth animations and transitions
- Fully responsive (mobile, tablet, desktop)

🎯 **Key Sections**
1. **Hero** - Powerful tagline with call-to-action buttons
2. **About** - Company overview with key metrics (3 operating fields, ~60% gas supply, 98% Bangladeshi workforce)
3. **Operations** - Three gas field profiles (Bibiyana, Jalalabad, Moulavi Bazar)
4. **Departments** - 17 department cards with searchable functionality
5. **Sustainability** - Community investment and corporate responsibility
6. **Careers** - Job opportunities and career links
7. **Contact** - Office locations in Dhaka and Sylhet

⚡ **Interactive Features**
- Mobile hamburger menu navigation
- Department search filter
- Fade-in animations on scroll (Intersection Observer)
- Hover effects and transitions
- Smooth scrolling navigation

📱 **Responsive Breakpoints**
- Desktop (1240px+)
- Tablet (950px - 1240px)
- Mobile (< 700px)

## Technology Stack

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with CSS variables and grid/flexbox
- **JavaScript** - Vanilla JS for interactivity (no frameworks)
- **Fonts** - Inter (body), Playfair Display (headings)

## Files

- `index.html` - Main website structure
- `styles.css` - Complete styling
- `script.js` - Interactive functionality

## Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/muntasirsohail/chevron-bangladesh-website.git
cd chevron-bangladesh-website
```

2. Serve locally (Python 3):
```bash
python -m http.server 8000
```

3. Open browser and visit:
```
http://localhost:8000
```

### Deploy to GitHub Pages

1. Push to `main` branch
2. Go to Repository Settings → Pages
3. Select "Deploy from a branch" → main branch
4. Your site will be live at `https://muntasirsohail.github.io/chevron-bangladesh-website/`
